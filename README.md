## 🚀 Projects

### 🌡️ [Fever Detection System](https://github.com/abiz-ewn/Fever-Detection-System-)
> `Python` `OpenCV` `DepthAI` `Thermal Imaging` `Luxonis OAK`

Contactless real-time fever screening system using a Luxonis OAK thermal camera. Detects and tracks people via thermal blob analysis and flags elevated body temperatures ≥37.5°C at **25 FPS**. Features an 8-frame EMA smoothing algorithm for stable, noise-resistant temperature readings and automated alerting via PoE/Ethernet-connected hardware.

---

### 🧬 [Bio-Sequence Converter](https://github.com/abiz-ewn/Bio-sequence-Converter)
> `Python` `Bioinformatics` `Molecular Biology`

Python-based bioinformatics tool that simulates the central dogma of molecular biology: **DNA → mRNA → Protein**. Transcribes DNA sequences to mRNA and translates codons to amino acids using a full codon table, with stop codon handling and unknown codon warnings.

---

### 👥 [Employee Management System](https://github.com/abiz-ewn/Employee-Management-System)
> `Java` `MySQL` `JDBC` `OOP` `DAO Pattern`

Full-stack CLI application for managing employee records, payroll, departments, and job titles. Implements the DAO design pattern with JDBC for secure CRUD operations, role-based HR/Admin interfaces with `AuthManager`, authentication, input validation, and persistent MySQL storage.

---

### 🔐 [Secure Password Generator](https://github.com/abiz-ewn/Secure-Password-Generator)
> `HTML` `CSS` `JavaScript`

Browser-based password generator with a clean, user-friendly UI. JavaScript powers the core randomization logic to generate strong, cryptographically sound passwords from configurable character sets, protecting accounts from weak-password vulnerabilities.
